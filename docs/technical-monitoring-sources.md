# مصادر المؤشرات الفنية في لوحة الإدارة

> قائمة التسليم المجمّعة لكل مسؤول: [infra-handoff-checklist.md](infra-handoff-checklist.md) (مصدر الحقيقة لما يُطلب؛ لا تعارض مع هذا الملف). لا يوجد أي مخزن مقاييس قائم يمكن الاعتماد عليه (انظر نتيجة البحث هناك).

API: `GET /api/admin/system-settings/technical-metrics` (صلاحية `settings.view` أو `settings.manage`)، ذاكرة مؤقتة 15 ثانية في الخادم. كل مؤشر: `value | valueText`, `unit`, `status` (measured / unavailable / error), `readAt`, `source`, `scope`, `reason`. لا قيمة تقديرية ولا صفر بدل المجهول. التحديث التلقائي في الواجهة اختياري وبحد أدنى 60 ثانية.

## 1. الجدول الكامل
| المؤشر (المفتاح) | يُقاس الآن؟ | النطاق بالعربية | المصدر | تحديث | ما تعرضه اللوحة عند غيابه |
|---|---|---|---|---|---|
| مدة التشغيل، RSS، الكومة، تأخر حلقة الأحداث (`api_*`) | نعم | **عملية الخادم الحالية فقط (نسخة واحدة)** | `process.*`, `perf_hooks` | كل قراءة | لا يغيب؛ تأخر الحلقة «غير متاح» حتى تتوفر عينات |
| عدد الطلبات، 2xx/4xx/5xx، 429، نسبة 5xx، p50/p95/p99 | نعم | **هذه النسخة فقط، آخر 15 دقيقة** (فئات توزيع؛ الحد الأعلى للفئة) | عدّاد داخلي بلا مسارات ولا مستخدمين | كل قراءة | «غير متاح: لا طلبات ضمن النافذة» |
| زمن SELECT 1، الحجم، إصابة الذاكرة، deadlocks، ملفات مؤقتة، التراجعات، الاتصالات، النشطة، نسبة حد الاتصالات | نعم | **قاعدة البيانات التي يتصل بها هذا الخادم** | `pg_stat_database`, `pg_stat_activity`, `pg_database_size` | كل قراءة (مهلة 3 ث) | «تعذّرت القراءة» مع سبب عام |
| استعلامات أبطأ من ثانية (`db_slow_queries`) | **لا** حتى تُفعَّل الإضافة | قاعدة البيانات، تراكمي منذ آخر إعادة ضبط | `pg_stat_statements` | كل قراءة | «غير متاح» + سبب (غير مثبّتة / غير قابلة للقراءة) |
| حالة النسخ الاحتياطي وعمره وحجمه ووقت آخر محاولة (`backup_*`) واختبار الاستعادة (`restore_*`) | **لا** حتى تكتب مهمة النسخ ملف الحالة | **آخر ما سجّلته مهمة النسخ** (لا يقيس النسخ نفسها) | ملف JSON (`BACKUP_STATUS_FILE`) | كل قراءة للملف | «غير متاح» / «ملف الحالة غير صالح» + العقد |
| استخدام CDN (تخزين، نطاق، تحويلات، ملفات) | نعم إذا ضُبط Cloudinary | **حساب Cloudinary المرتبط** | Cloudinary Admin API | كاش 5 دقائق (حصة الواجهة) | «غير متاح: التكامل غير مهيأ» أو «تعذّرت القراءة» |
| ذاكرة الحاوية، نسبتها من الحد، معالج الحاوية | نعم داخل حاوية | **حاوية الباك فقط (ليس المضيف ولا بقية الخدمات)** | cgroup v2/v1 | كل قراءة (المعالج يحتاج قراءتين) | «غير متاح: ملفات cgroup غير مقروءة» |
| امتلاء/مساحة حرة | نعم | **نظام الملفات الذي يحوي مجلد التطبيق داخل الحاوية (وليس المضيف كاملًا)** | `statfs` | كل قراءة | «تعذّرت قراءة نظام الملفات» |
| معالج/ذاكرة/قرص المضيف (`host_*`) | **لا** | **المضيف كاملًا**، كما يصرّح به المصدر في حقل `scope` | `HOST_METRICS_URL` | كاش 60 ث | «غير متاح» + اسم المتغير |
| حاويات تعمل/لا تعمل/إعادات التشغيل (`ctr_running`…) | **لا** | **الحاويات التي يغطيها المصدر** (العدد مذكور) | `CONTAINER_STATUS_URL` | كاش 60 ث | «غير متاح» + اسم المتغير |
| طلبات الحافة ونسبة الإصابة (`edge_*`) | **لا** | **طبقة الحافة/CDN، آخر N دقيقة** | `EDGE_STATS_URL` | كاش 60 ث | «غير متاح» + اسم المتغير |
| WAF (`waf_blocked`) | **لا** | **جدار الحماية، آخر N دقيقة** | `WAF_STATUS_URL` | كاش 60 ث | «غير متاح» + اسم المتغير |
| تجميع API بين كل النسخ | **لا** | **كل النسخ** (غير متاح؛ كل رقم يخص نسخة واحدة معرّفة بـ `instance.id`) | لا مصدر | — | ملاحظة في اللوحة |
| السجل التاريخي والاتجاهات | **لا** | — | لا مصدر | — | «غير متاح» + ملاحظة |

## 2. ما يجب أن يوفّره المسؤول لكل مصدر ناقص
القاعدة العامة للمحوّلات الأربعة: نقطة **GET** تعيد `application/json` (حتى 16 KB)، بلا إعادة توجيه، تصل من حاوية الـAPI، ويُضاف مضيفها مع المنفذ إلى `MONITORING_ALLOWED_HOSTS` (قائمة مفصولة بفواصل)، وتُحمى اختياريًا برمز Bearer في المتغير `*_TOKEN`. `collectedAt` بتوقيت ISO ولا يزيد عمره عن 15 دقيقة. الحقول الإضافية ترفض الرد.

| المصدر | المتغيرات | العقد | المسؤول |
|---|---|---|---|
| المضيف | `HOST_METRICS_URL`, `HOST_METRICS_TOKEN` | `{schemaVersion:1, collectedAt, scope (نص حتى 80 حرفًا يصف ما قيس، مثل «المضيف كاملًا»), cpuPercent 0-100, memoryUsedBytes, memoryTotalBytes, diskUsedBytes, diskTotalBytes}` (الحقول الرقمية اختيارية) | فريق البنية (وكيل مقاييس على المضيف، مثل node exporter خلف طبقة JSON صغيرة) |
| الحاويات | `CONTAINER_STATUS_URL`, `CONTAINER_STATUS_TOKEN` | `{schemaVersion:1, collectedAt, containers:[{name, state: running\|restarting\|exited\|paused\|dead\|created, restartCount}]}` حتى 50 عنصرًا؛ وكيل Docker للقراءة فقط (لا socket مباشر في الحاوية) | فريق البنية |
| الحافة | `EDGE_STATS_URL`, `EDGE_STATS_TOKEN` | `{schemaVersion:1, collectedAt, windowMinutes, requests, cacheHitRatioPercent}` | فريق البنية / مزوّد CDN |
| WAF | `WAF_STATUS_URL`, `WAF_STATUS_TOKEN` | `{schemaVersion:1, collectedAt, windowMinutes, blockedRequests, challengedRequests?}` | فريق البنية / مزوّد WAF |
| النسخ الاحتياطي | `BACKUP_STATUS_FILE`, `BACKUP_STALE_HOURS`, `RESTORE_TEST_STALE_DAYS` | `docs/backup-status-contract.md` (وقسم HANDOFF فيه) | صاحب جدول النسخ (من يملك الوصول للخادم) |
| Cloudinary | `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` (موجودة للرفع) | لا شيء إضافي؛ يُظهر الاستخدام تلقائيًا إذا لم تكن القيمة `local-dev` | صاحب الحساب |
| قرص التطبيق | `MONITOR_DISK_PATH` (اختياري، الافتراضي مجلد العمل) | مسار داخل الحاوية؛ لا يُعرض | فريق البنية |

## 3. `pg_stat_statements` (يُنفَّذ بواسطة مالك قاعدة البيانات، لا يغيّر التطبيق أي إعداد)
1. في `postgresql.conf` (أو أمر التشغيل للحاوية): `shared_preload_libraries = 'pg_stat_statements'` (أضفها إلى القائمة إن وُجدت غيرها).
2. **إعادة تشغيل** خادم PostgreSQL (التغيير لا يسري بإعادة تحميل فقط).
3. في قاعدة تطبيق وسيط: `CREATE EXTENSION IF NOT EXISTS pg_stat_statements;`
4. منح دور التطبيق حق القراءة: `GRANT pg_read_all_stats TO <app_role>;` (أو منح SELECT على العرض عند أقل صلاحية مناسبة).
5. **كيف يكتشفها التطبيق:** استعلام قراءة فقط على `pg_extension` ثم على العرض `pg_stat_statements`. غير مثبّتة ← «غير متاح: الإضافة غير مثبّتة…»؛ مثبّتة لكن العرض غير مقروء (لم تُحمَّل أو لا صلاحية) ← «غير متاح: العرض غير قابل للقراءة…»؛ وإلا يعرض عدد الاستعلامات التي متوسطها أبطأ من ثانية (تراكمي منذ آخر إعادة ضبط).

## 4. تجميع API بين النسخ والسجل التاريخي
- **الموصى به:** مسار سلاسل زمنية خارجي (Prometheus أو ما يعادله) يجمع من كل نسخة ويخزن التاريخ؛ لا جدول جديد في قاعدة التطبيق.
- **أقل عقد تصدير يمكن للتطبيق تقديمه لاحقًا:** نقطة `/metrics` بصيغة Prometheus النصية محمية بالرمز، تتضمن: `waseet_http_requests_total{class="2xx|3xx|4xx|5xx"}`, عداد 429، مخطط تكراري لزمن الاستجابة بنفس الفئات (10/25/50/100/250/500/1000/2500/5000 ms)، وقياسات العملية؛ مع وسم `instance` المعتم. **غير مبنية الآن.**
- **ما لم يُبنَ:** التجميع بين النسخ، التاريخ، التنبيهات، التتبع لكل مسار (لا مسارات في العدّاد عمدًا للخصوصية).
- **لا ترحيل (migration) في هذه الدفعة:** لا جدول جديد لأن الحل الصحيح خارجي؛ لذلك لم يلزم أي تمرين على قاعدة `qa_iso_mon_*` أو نسخة dev مستعادة.
